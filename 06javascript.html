6️⃣ JavaScript

JavaScript pridáva do HTML stránok interaktivitu – napríklad reagovanie na kliknutia.

💻 Kód:

<p id="text">Tento text zmení farbu, keď klikneš na tlačidlo.</p>
<button onclick="zmenFarbu()">Zmeniť farbu</button>

<script>
function zmenFarbu() {
  const farby = ['#ff6347', '#0077cc', '#32cd32', '#ffa500', '#8a2be2'];
  const nahodnaFarba = farby[Math.floor(Math.random() * farby.length)];
  document.getElementById('text').style.color = nahodnaFarba;
}
</script>

🔍 Ukážka:

Tento text zmení farbu, keď klikneš na tlačidlo.
