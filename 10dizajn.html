🔟 Responzívny dizajn

Responzívny dizajn zabezpečí, že sa web prispôsobí veľkosti obrazovky. Používame CSS pravidlo @media, ktoré mení štýly podľa šírky zariadenia.

➡️ Príklad kódu:

<div class="kontajner">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>

<style>
.kontajner { display: flex; gap: 15px; }
.box { background: blue; color: white; padding: 20px; }
@media (max-width: 600px) { .kontajner { flex-direction: column; } }
</style>

📱 Výsledok v praxi:

1
2
3

💡 Skús zmenšiť okno — boxy sa zoradia pod seba!
