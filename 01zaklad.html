1️⃣ Základy HTML

Tu sa naučíš, ako vyzerá najjednoduchší HTML dokument a čo znamenajú jeho časti.

💻 Ukážkový kód:

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Moja prvá stránka</title>
</head>
<body>

  <h1>Ahoj svet!</h1>
  <p>Toto je moja prvá HTML stránka.</p>

</body>
</html>

🧩 Vysvetlenie:

<!DOCTYPE html> — oznamuje prehliadaču, že ide o moderný HTML5 dokument.
<html> ... </html> — všetko, čo je vo vnútri, tvorí celú stránku.
<head> ... </head> — obsahuje informácie o stránke (názov, kódovanie, meta údaje).
<body> ... </body> — tu je viditeľný obsah pre používateľa (text, obrázky, tlačidlá...).
<h1> — hlavný nadpis.
<p> — bežný textový odstavec.
