4️⃣ Zoznamy a tabuľky

V tejto kapitole sa naučíš, ako vytvoriť zoznam položiek a jednoduchú tabuľku.

🧾 Zoznamy

<ul>
  <li>Jablko</li>
  <li>Banán</li>
  <li>Pomaranč</li>
</ul>

<ol>
  <li>Otvor VS Code</li>
  <li>Vytvor nový súbor</li>
  <li>Napíš HTML kód</li>
</ol>
<ul> = nečíslovaný zoznam (s bodkami)
<ol> = číslovaný zoznam (1, 2, 3…)
<li> = položka v zozname

🧩 Ukážka v praxi:

Nečíslovaný zoznam:

  • Jablko
  • Banán
  • Pomaranč

Číslovaný zoznam:

  1. Otvor VS Code
  2. Vytvor nový súbor
  3. Napíš HTML kód

<tr> = riadok tabuľky
<th> = hlavička tabuľky (tučné, v hornej časti)
<td> = bunka tabuľky (bežné dáta)
