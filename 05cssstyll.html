5️⃣ CSS Štýly

CSS (Cascading Style Sheets) slúži na úpravu vzhľadu HTML prvkov — farby, veľkosti, rozloženie, atď.

💻 Kód:

<div class="box">Box</div>

<style>
.box {
  width: 150px;
  height: 150px;
  background-color: tomato;
  border: 3px solid #0077cc;
  border-radius: 12px;
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
}
</style>
