1️⃣4️⃣ Publikovanie na GitHub Pages

Postup

  1. Vytvor GitHub účet a nový repozitár (napr. moja-stranka).
  2. Pridaj HTML, CSS, JS súbory do repozitára.
  3. V nastaveniach repozitára vyber Pages a nastav branch, z ktorého sa má publikovať (napr. main).
  4. GitHub Pages automaticky vytvorí URL tvojho projektu: https://uzivatel.github.io/moja-stranka/

Ukážka jednoduchého HTML súboru

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <title>Moja stránka</title>
</head>
<body>
  <h1>Vitaj na mojej GitHub Pages!</h1>
  <p>Toto je jednoduchý príklad.</p>
</body>
</html>

Príklad publikovanej stránky

Vitaj!

Toto je tvoja stránka publikovaná na GitHub Pages.

⬅️ Späť na hlavnú stránku
